
# BND Diesel — Sistema de Gestão de Orçamentos

## Sobre o projeto

O BND Diesel é um MVP de aplicação web responsiva desenvolvido com o objetivo de apoiar a organização dos processos administrativos da oficina, facilitando o gerenciamento de clientes, veículos e orçamentos.

A solução busca centralizar informações e simplificar o acompanhamento das situações dos orçamentos, contribuindo para a organização e a eficiência da rotina administrativa.

## Objetivo

Desenvolver uma aplicação simples e acessível que permita organizar os principais registros administrativos da oficina BND Diesel.

## Funcionalidades previstas

- Cadastro de clientes.
- Cadastro de veículos.
- Registro de serviços.
- Criação de orçamentos.
- Consulta e atualização do status dos orçamentos.

## Tecnologias previstas

- Python
- Django
- Bootstrap
- PostgreSQL
- Psycopg

## Arquitetura

A aplicação seguirá uma arquitetura monolítica em camadas, com separação entre apresentação, regras de negócio e persistência de dados.

## Qualidade de software

O desenvolvimento utilizará Git e GitHub para controle de versão, testes automatizados para verificação das funcionalidades e GitHub Actions para integração contínua (CI).
